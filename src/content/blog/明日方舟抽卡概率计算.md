明日方舟抽卡概率计算。  
  
我们定义$dp[i][j]$表示抽卡到第$j$次时出了第$i$次货的概率，则有

$$

dp[i][j]=\sum_{k=i-1}^{j-1}{dp[i-1][k]*dp[1][j-k]}(i>1)

$$

预处理$dp[1][i]$即可。

上代码

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010;
long double dp[12][N],s[N],f[N];
//dp[i][j]表示抽卡第j次时第i次出货的概率
int main(){
    long double p=0.02,q=1;
    for(int i=1;i<=100;++i){
        if(i>50)
            p+=0.02;
        dp[1][i]=q*p;
        q*=(1-p);
    }
    for(int i=1;i<=100;++i)
        printf("第%d次时第一次出货的概率为%.10Lf\n",i,dp[1][i]);
    //这里均指第一次出货。
    double E_dp=0;//期望出货所需抽卡次数
    for(int i=1;i<=100;++i)
        E_dp+=i*dp[1][i];
    printf("期望出货一次所需抽卡次数:%.10Lf\n",E_dp);
    f[0]=1;
    for(int i=1;i<=100;++i){
        s[i]=s[i-1]+dp[1][i];
        f[i]=1-s[i];
        printf("出货一次<=%d抽卡次数的概率%.10Lf\n",i,s[i]);//即dp[1][1]+...+dp[1][i]
    }
    
    for(int i=2;i<=10;++i){
        for(int j=1;j<=1000;++j)
            for(int k=i-1;k<j;++k)
                dp[i][j]+=dp[i-1][k]*dp[1][j-k];
    }
    long double ans=0;
    int X=700,ans_id=0;
    for(int i=X-100;i<=X;++i){
        long double z_ans=dp[10][i]*f[X-i];
        if(z_ans>ans){
            ans=z_ans;
            ans_id=i;
        }
    }
    printf("当第%d次出货第10次且总抽卡次数为%d时的最大概率为%.14Lf\n",ans_id,X,ans);
    return 0;
}
```

注：上面代码的q指的是前面均为出货的概率，p代表当前出货率。

接下来我们对此进行分析。  
代码运行结果显示，期望出货抽卡次数为35次。  
35次内出货概率约为50%，50次内出货概率约为63.5%，70次内出货概率99.84%，88次内**不出货**概率约为$ 2*10^{-8}\\\\%$

这是什么概念呢？

十连中出五个六星的概率是$0.02^{5}*0.98 ^{5} * C(10,5)$约为$7*10^{-5} \\\\% $

好家伙，你88次还不出货的概率比十连中出五星概率小几千倍。  
接下来考虑平均出货。  
有的人说自己80级平均70次出一个六星？  
我们假设他抽了700次10个六星吧，设这个概率最大为$ans$，则有

$$

ans=max\{dp[10][i]*f[700-i]\}(600\leq i\leq 700,其中f[i]表示i发不出的概率)

$$

我们可以得到当第640次出第10次且后60次不出货的概率是最大的，即700次平均70次1六星的最大概率，其约为$9.15*10^{-10}\\\\%$  
  
当然，这只是700次出了10次的概率，如果是出了<=10次的概率求到的仍约为$9.15*10^{-10}\\\\%$，因为<=9次的远小于=10次的  
  
这个概率极其的小，比十连出五个六星概率小的多得多，然而我们总是能看到说自己什么90发出货，什么高等级平均70次一个之类的，却很少见到有十连四个，五个六星的，这原因相信不说也应该懂了吧…  
  
且根据期望的相关性质，出货k次的期望抽卡次数为35\*k。
