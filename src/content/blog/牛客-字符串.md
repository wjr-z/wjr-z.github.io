基础中的基础题。

## 题目描述：

[题目链接](https://ac.nowcoder.com/acm/problem/18386)  
给出一个长度为 n 的仅由小写字母构成的字符串，求出包含了所有的小写字母子串的最小长度。

## 题解：

很显然是用尺取法  
对于每一个右端点，求出最大的左端点并且能满足条件即可，这样的话，当右端点往右移动时，显然这样的左端点也是往右移动的  
对于快速求出是否符合条件只需要用桶存每个字母出现次数即可，每次移动右端点后，将左端点移动到最后一个使得所有字母都出现过的位置，这个位置也是第一个至少一个字母未出现的位置的左边一个。

参考代码如下：  

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1e6+10;
char s[N];
int n;
int num[30],res;
inline void add(int x) {
    if(++num[s[x]-'a']==1)--res;
}inline void del(int x) {
    if(--num[s[x]-'a']==0)++res;
}
int main() {
    res=26;
    scanf("%s",s+1);
    int n=strlen(s+1);
    int L=1,R=0;
    int ans=n+1;
    while (R <= n) {
        while(R<=n&&res)add(++R);
        if(R>n)break;
        while(!res)del(L++);
        ans=min(ans,R-L+2);
    }
    printf("%d\n",ans);
    return 0;
}
```
