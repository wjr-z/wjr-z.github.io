## A.一道GCD问题

[题目链接](https://ac.nowcoder.com/acm/contest/10743/A)

题目描述：  
给定一个数组a，求每个数加上k后能得到的最大gcd，并求出最小的非负整数k。

题解：  
假设最大的gcd值为GCD，则  
a\[1\]+k=GCD\*b\[1\]  
a\[2\]+k=GCD\*b\[2\]  
a\[3\]+k=GCD\*b\[3\]  
…  
做个差分，可以发现与k无关了，GCD为查分数组的gcd，然后就做出来了。

参考代码

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1e5+10;
int a[N];
inline int gcd(int a,int b){return !b?a:gcd(b,a%b);}

int main(){
    int n;
    scanf("%d",&n);
    for(int i=1;i<=n;++i)scanf("%d",&a[i]);
    int GCD=abs(a[2]-a[1]);
    for(int i=3;i<=n;++i){
        GCD=gcd(GCD,abs(a[i]-a[i-1]));
    }
    int k;
    if(a[1]%GCD==0)k=0;
    else k=GCD-a[1]%GCD;
    printf("%d %d\n",GCD,k);
    return 0;
}
```

## B.又一道 GCD 问题

[题目链接](https://ac.nowcoder.com/acm/contest/10743/B)

题目描述：略。

题解：  
经典套路题。将比较难直接求的问题转化为求可行性。  
假设i+1个gcd为x，则必定有大于等于i+1个a是x的倍数。  
因为求最大的gcd，则求出一个ans，有大于等于i+1个是ans的倍数，且ans最大化即可。

我们令s\[i\]表示可以整除i的个数，令ans\[i\]表示s\[x\]=i的所有x的最大值。  
这样ans\[i\]即表示恰好有i个是ans\[i\]的倍数，且ans\[i\]最大化。

最后因为需要求的是大于等于而非等于，从后往前ans\[i\]=max(ans\[i\],ans\[i+1\])即可。

参考代码

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1e5+10;
int a[N];
int s[N],ans[N];
int n;
int main(){
    scanf("%d",&n);
    int x,m=0;
    for(int i=1;i<=n;++i)scanf("%d",&x),++a[x],m=max(m,x);
    for(int i=1;i<=m;++i)
        for(int j=i;j<=m;j+=i)
            s[i]+=a[j];
    for(int i=1;i<=m;++i)
        ans[s[i]]=max(ans[s[i]],i);
    for(int i=n;i>=1;--i)ans[i]=max(ans[i],ans[i+1]);
    for(int i=2;i<=n;++i)
        printf("%d ",ans[i]);
    printf("\n");
    return 0;
}
```

## C.条件

[题目链接](https://ac.nowcoder.com/acm/contest/10743/C)

题目描述：略。

题解：  
给定若干有向边，判断x是否能到达y，并且询问次数q大，n较大，一般是用floyd进行预处理。  
但是floyd复杂度是$O(n^3)$，显然是过不了的。  
因为此题只是判断是否能否到达，并否最短路什么的，因此可以用bitset优化，复杂度$O(n^3/w)$。(w为32/64)  
将两种情况的边用两个bitset存起来，一个是所有一定存在的边，一个是一定和可能存在的边，其他就和普通floyd差不多了。

参考代码

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=1010;
int n,m1,m2,q;
bitset<N>a[N],b[N];
int main(){
    scanf("%d%d%d%d",&n,&m1,&m2,&q);
    //a[i]表示所有一定存在的边可以到达的点
    //b[i]表示所有可能和一定存在的边可以到达的点
    for(int i=1;i<=n;++i)
        for(int j=1;j<=n;++j){
            b[i][j]=1;
            if(i==j)a[i][j]=1;
        }
    int x,y;
    for(int i=1;i<=m1;++i){
        scanf("%d%d",&x,&y);
        a[x][y]=1;
    }
    for(int i=1;i<=n;++i)
        for(int j=1;j<=n;++j){
            if(!a[j][i])continue;
            a[j]|=a[i];
            //如果j可以到达i，则j可以到达的点包含i可以到达的点
        }
    for(int i=1;i<=m2;++i){
        scanf("%d%d",&x,&y);
        b[x][y]=0;
    }
    for(int i=1;i<=n;++i)
        for(int j=1;j<=n;++j){
            if(!b[j][i])continue;
            b[j]|=b[i];
            //如果j可以到达i，则j可以到达的点包含i可以到达的点
        }
    while(q--){
        scanf("%d%d",&x,&y);
        if(a[x][y])printf("Yes ");
        else printf("No ");
        if(b[x][y])printf("Yes\n");
        else printf("No\n");
    }
    return 0;
}
```

## D.Lots of Edges

[题目链接](https://ac.nowcoder.com/acm/contest/10743/D)

题目描述：  
有n个点，每个点有点权$a_{1}\sim a_{n}$，若 $ a\_{i} \& a\_{j}=0$（指二进制按位与），则在i,j间连一条边权为1的边。  
求 S 到$1\sim n$的最短路。

输入描述：  
第一行两个正整数 n,S 。  
接下来一行 n 个非负整数，第 i 个为 $a\_i$ 。  
  
对于所有数据，$1\le S\le n\le 10^5$，$0\le a\_i\le 131071$。

输出描述:  
一行 n 个整数，第 i 个为 S 到 i 的最短路长度。不能到达输出 -1。

题解：  
1.[常规题解](https://www.nowcoder.com/discuss/587283?type=101)  
2.优化建图题解。  
常规做法复杂度很高，不过因为此题可能不想考优化建图，因此并没有卡复杂度，常规做法复杂度为$O(n^{1.587})$。  
  
此题可以优化建图，对于值x只向其二进制表示中少某一位1的值y建边权为0的单向边即可，例如101(2)->001(2),101(2)->100(2)，但是不向000(2)建边。  
然后将所有存在的值x（即a中有的）向x^W($W=2^k-1$，且W大于等于a的最大值)建边权为1的单向边。  
  
建边后跑dijkstra，起点需要从a\[S\]^W开始，且此点初始距离设置为1，具体细节可以自行思考。  
该方法复杂度为$O(nlogn)$

参考代码

```c++
#include <bits/stdc++.h>
using namespace std;
const int W=131071,N=W+100,M=2e6,inf=1e6+7;
int d[N],nxt[M],to[M],val[M],tot;
int dis[N];
struct node{
    int id,dis;
    node (int a=0,int b=0){
        id=a;
        dis=b;
    }
    inline bool operator<(const node&other)const{
        return dis>other.dis;
    }
};
priority_queue<node>q;
inline void ins(int a,int b,int v){
    to[++tot]=b;
    nxt[tot]=d[a];
    d[a]=tot;
    val[tot]=v;
}
int n,S;
int a[N];
bool vis[N];
inline void dijkstra(){
    memset(dis,0x3f,sizeof(dis));
    int start=a[S]^W;
    dis[start]=1;
    q.push(node(start,1));
    while(!q.empty()){
        node tmp=q.top();
        q.pop();
        if(vis[tmp.id])continue;
        vis[tmp.id]=1;
        for(int i=d[tmp.id];i;i=nxt[i]){
            int u=to[i];
            if(dis[u]>tmp.dis+val[i]){
                dis[u]=tmp.dis+val[i];
                q.push(node(u,dis[u]));
            }
        }
    }
}
#define lb(x) x&-x
bool f[N];
inline void build(){
    for(int i=1;i<=W;++i){
        int p,q;
        p=i;
        while(p){
            q=lb(p);
            ins(i,i^q,0);
            p-=q;
        }
    }
    for(int i=0;i<=W;++i)
        if(f[i])ins(i,i^W,1);
}
int main(){
    scanf("%d%d",&n,&S);
    for(int i=1;i<=n;++i)
        scanf("%d",&a[i]),f[a[i]]=1;
    build();
    dijkstra();
    for(int i=1;i<=n;++i){
        if(i==S){
            printf("0 ");
            continue;
        }
        if(dis[a[i]]<=inf)printf("%d ",dis[a[i]]);
        else printf("-1 ");
    }
    return 0;
}
```
