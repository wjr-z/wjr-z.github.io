## 题目描述：

给了 n 个武器，每个武器有一个重量 a ，并且给了一个天平，现在你每次都可以从这些武器中选择若干个武器并放到天平上，但是只有天平两边重量相差 m 以内你才能拿走，并且拿走的武器不能再放到天平上，问你最多能拿走的武器总重量。

## 题解：

实际上如果答案最优，则拿若干次一定不优于拿一次。  
假设拿的第一次左右两边相差 x ，第二次左右两边相差 y ，则一定有 $|x-y|\leq m$（第二次重的一边放到第一次轻的一边），所以其实无论拿多少次都可以变成只拿一次。  
  
这样就是个简单 dp 了。  
设 $dp[i][j]$ 表示前 i 个武器天平重量相差 j 能拿走的最大武器重量  
  
转移：

$$

dp[i][j]=max(dp[i-1][j],dp[i-1][j+a[i]],dp[i-1][|j-a[i]|])

$$

参考代码如下：  

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=105;
int n,m;
int dp[2][N*N],a[N];//dp[i][j]表示前i个左右两边相差j的最大重量
int main(){
    scanf("%d%d",&n,&m);
    for(int i=1;i<=n;++i){
        scanf("%d",&a[i]);
    }
    int now=0,las=1;
    memset(dp,0xf3,sizeof(dp));
    dp[0][0]=0;
    for(int i=1;i<=n;++i){
        now^=1,las^=1;
        for(int j=0;j<=10000;++j){
            int x;
            x=abs(j-a[i]);
            dp[now][j]=dp[las][j];
            dp[now][j]=max(dp[now][j],dp[las][x]+a[i]);
            x=j+a[i];
            if(x<=10000)
                dp[now][j]=max(dp[now][j],dp[las][x]+a[i]);
        }
    }
    int ans=0;
    for(int i=0;i<=m;++i)
        ans=max(ans,dp[now][i]);
    printf("%d\n",ans);
    return 0;
}
```

  
用了下滚动数组优化。
