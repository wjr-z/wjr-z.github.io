## 题目描述

> 这里有一个n\*m的矩阵，请你选出其中k个子矩阵，使得这个k个子矩阵分值之和最大。  
> 注意：选出的k个子矩阵 不能相互重叠。

[题目链接](https://ac.nowcoder.com/acm/problem/20242)  

题解：  
题目范围很重要，$m\leq 2$，当m为1时即简单的数组中取k段连续和的最大值，令dp\[i\]\[j\]表示前i个取j个子矩阵的最大值即可。  
当m=2时，即将上述的二维dp改为三维dp即可，令dp\[i\]\[j\]\[k\]表示第一列前i个，第二列前j个中取k个子矩阵的最大值。  
dp\[i\]\[j\]\[k\]初始为max(dp\[i-1\]\[j\]\[k\],dp\[i\]\[j-1\]\[k\])，表示不取的转移。  
1.如果是当前取一个一列的矩阵，则分别在两列进行转移：

$$

\begin{aligned} dp[i][j][k]=max\{dp[p][j][k-1]+s1[i]-s1[p]\}\\ dp[i][j][k]=max\{dp[i][p][k-1]+s2[i]-s2[p]\} \end{aligned}

$$

2.如果是取一个两列的矩阵，则只能在i=j时进行转移：

$$

\begin{aligned} dp[i][i][k]=max\{dp[p][p][k-1]+s1[i]+s2[i]-s1[p]-s2[p]\} \end{aligned}

$$

其中s1表示第一列前缀和，s2表示第二列前缀和。

不过后来我发现这样做还是有些问题的，如果m=1并且第一列全为负数，这样第二列当做0算，这样取的k个子矩阵可能有第二列的，但这是非法的，因此需要考虑将m=1和m=2分开来做或者是第二列前缀和进行修改。  
因为数据范围并不大，因此对第二列前缀和修改即可，而且此题貌似数据也很弱，不考虑也能过。

参考代码

```c++
#include <bits/stdc++.h>
using namespace std;
int dp[105][105][12],s[105][3];
int n,m,k;
int a[105][3];
int main(){
    memset(dp,0xf3,sizeof(dp));
    scanf("%d%d%d",&n,&m,&k);
    for(int i=1;i<=n;++i)
        for(int j=1;j<=m;++j){
            scanf("%d",&a[i][j]);
            s[i][j]=s[i-1][j]+a[i][j];
        }
    for(int i=0;i<=n;++i)
        for(int j=0;j<=n;++j)
            dp[i][j][0]=0;
    if(m==1){
        for(int i=1;i<=n;++i)
            s[i][2]=-i*1e7;
    }
    for(int p=1;p<=k;++p)//取p个子矩阵
        for(int i=1;i<=n;++i)//第一列
            for(int j=1;j<=n;++j){//第二列
                dp[i][j][p]=max(dp[i-1][j][p],dp[i][j-1][p]);
                for(int l=0;l<i;++l)
                    dp[i][j][p]=max(dp[i][j][p],dp[l][j][p-1]+s[i][1]-s[l][1]);
                for(int l=0;l<j;++l)
                    dp[i][j][p]=max(dp[i][j][p],dp[i][l][p-1]+s[j][2]-s[l][2]);
                if(i==j)
                    for(int l=0;l<i;++l)
                        dp[i][j][p]=max(dp[i][j][p],dp[l][l][p-1]+s[i][1]+s[i][2]-s[l][1]-s[l][2]);
            }
    printf("%d\n",dp[n][n][k]);
    return 0;
}
```
