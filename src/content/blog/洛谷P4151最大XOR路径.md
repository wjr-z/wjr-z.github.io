### 题目描述

给定一个无向图，让你求从 1 到 n 的路径最大异或和。  
[题目链接](https://www.luogu.com.cn/problem/P4151)  

### 题解

一条边如果经过偶数次则这条边对答案无影响，如果经过奇数次则有影响。  
不难发现任意两条路径异或后其实都是若干个环，证明省略。  
接下来考虑如何找到所有的环。  
因为异或的性质，因此我们并非需要真的找到所有的环，实际上要找的环十分有限。  
我们用dfs，每搜到一个点打上 vis 标记，如果下一个点已经 vis 过了，则这个环的异或和丢进线性基，否则继续深搜。  
这样为什么是对的呢？  
事实上这样很多的环套环是搜不到的。  
当我们找到一个环后，这个环因为其所有点均 vis 过，因此包含此环一部分的其他环无法被找到。  
不过所有的环其实均为若干个简单环异或而成，此处简单环指不可能与其他若干环异或的到新环，而简单环我们可以证明一定都能被找到，加入存在某简单环未在dfs中找到，则说明必定存在环上P，在找到该环前访问过该环上的某点Q，则P，Q之间必定至少存在一个环，说明该环不是简单环，因此可以证明所有简单环一定是能被找到的。  
然后所有的环都能由若干个简单环异或而成，用线性基便可以得到所有可能异或出的值。  
再回到最初说的两条路径异或和都是若干个环，这样的话最优路径和我们随便找的一条路径只相差若干个环，将所有的简单环的异或值丢进线性基，然后随便用一个1 到 n 的路径异或和找到异或最大值即可。

参考代码

```c++
#include <bits/stdc++.h>
using namespace std;
const int N=50010,M=100010;
long long f[70];
inline void insert(long long x){
    for(int i=60;i>=0;--i)
        if(x&(1ll<<i)){
            if(f[i])x^=f[i];
            else{
                f[i]=x;
                return;
            }
        }
}
int d[N],nxt[M<<1],to[M<<1],tot;
long long cost[M<<1];
inline void ins(int a,int b,long long c){
    to[++tot]=b;
    nxt[tot]=d[a];
    d[a]=tot;
    cost[tot]=c;
}
long long dis[N];
bool vis[N];
inline void dfs(int x,long long v){
    dis[x]=v;vis[x]=1;
    for(int i=d[x];i;i=nxt[i]){
        int u=to[i];
        if(!vis[u])dfs(u,v^cost[i]);
        else insert(v^dis[u]^cost[i]);
    }
}int n,m;
inline long long Max(long long v){
    long long ans=v;
    for(int i=60;i>=0;--i)
        if((ans^f[i])>ans)ans^=f[i];
    return ans;
}
int main(){
    int u,v;
    long long w;
    scanf("%d%d",&n,&m);
    for(int i=1;i<=m;++i){
        scanf("%d%d%lld",&u,&v,&w);
        ins(u,v,w);
        ins(v,u,w);
    }
    dfs(1,0);
    printf("%lld\n",Max(dis[n]));
    return 0;
}
```
