经典的回文串相关的 DP 题，理解了如何用$O(n^2)$求解回文串，这题会比较简单。

对于求解最长回文串，可以用复杂度为$O(n)$的 Manacher 算法，或者回文自动机，但是此题只需要 DP 即可。  
对于 DP 求解回文串，记 dp\[i\]\[j\] 为 i 到 j 是否是回文串即可，转移很简单，当 s\[i\] == s\[j\] 时 dp\[i\]\[j\] = dp\[i+1\]\[j-1\] 即可  
如果 i+1 到 j-1 是回文串，则 i 到 j 也是回文串，反之则不是。

此题有两个字符串，但其实 DP 只用略微修改即可  
因为合并出的字符串中连续的一段必定是原来的分别来自两个字符串中连续的一段合并而来的（可以为空）  
这样的话用个四维 dp 即可，记 dp\[i\]\[j\]\[k\]\[l\] 表示第一个串 i 到 j 和第二个串 k 到 l 构成的串是否能是回文串  
此时注意，转移有四种，转移：

$$

\begin{aligned} dp[i][j][k][l]|=dp[i+1][j-1][k][l]\;(s[i]==s[j]) \\ dp[i][j][k][l]|=dp[i+1][j][k][l-1]\;(s[i]==g[l]) \\ dp[i][j][k][l]|=dp[i][j-1][k+1][l]\;(s[j]==g[k]) \\ dp[i][j][k][l]|=dp[i][j][k+1][l-1]\;(g[k]==g[l]) \end{aligned}

$$

若某个 dp\[i\]\[j\]\[k\]\[l\] 为 1 ，则说明这是一个回文串，更新下答案即可。

参考代码如下：  

```c++
#include <bits/stdc++.h>
using namespace std;
const int N = 52;
char s[N], g[N];
int dp[N][N][N][N];
int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int ans = 0;
        scanf("%s%s", s + 1, g + 1);
        int n = strlen(s + 1), m = strlen(g + 1);
        for (int i = 0; i <= n; ++i)
            for (int j = 0; j <= m; ++j) {
                for (int l = 1; l + i - 1 <= n; ++l) {
                    int r = l + i - 1;
                    for (int L = 1; L + j - 1 <= m; ++L) {
                        int R = L + j - 1;
                        if (i + j <= 1)
                            dp[l][r][L][R] = 1;
                        else {
                            dp[l][r][L][R] = 0;
                            if (s[l] == s[r])dp[l][r][L][R] |= dp[l + 1][r - 1][L][R];
                            if (s[l] == g[R])dp[l][r][L][R] |= dp[l + 1][r][L][R - 1];
                            if (g[L] == s[r])dp[l][r][L][R] |= dp[l][r - 1][L + 1][R];
                            if (g[L] == g[R])dp[l][r][L][R] |= dp[l][r][L + 1][R - 1];
                        }
                        if (dp[l][r][L][R])ans = max(ans, i + j);
                    }
                }
            }
        printf("%d\n", ans);
    }
    return 0;
}
```
