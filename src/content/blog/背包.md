## 题目描述：

[题目链接](https://ac.nowcoder.com/acm/problem/17315)  
容量为 V 的背包，有 n 个物品 ，每一个物品有一个价值 a 和重量 b ，现在要你选择 m 个物品装进背包，求出这 m 个物品价值中位数的最大值。

## 前言

题解说的是 m 为偶数时取中位数较大的一个枚举也行，但是貌似这个没单调性？（我枚举最大数没做出来…

## 题解：

这题需要求中位数的最大值，因此需要先将所有物品按照从小到大排序  
然后将问题从求解中位数最大值变成判断中位数是 x 的可能性  
即我们枚举中位数，然后判断是否能成立

1.  m 是奇数时（ m = 2k + 1 )  
    此时我们枚举 $a\_i(k+1\leq i \leq n-k)$ ，如果 i 重量最小的 k 个与 i 后重量最小 k 个与 i 的重量之和小于等于 V ，则说明中位数可以为$a\_i$。
2.  m 是偶数时（ m = 2k ）  
    此时枚举中位数中较小的一个，要使中位数最大，则中位数中较大的一个要尽量大。  
    我们设$pre\_i$表示前 i 个中重量最小的 k 个，设$suf\_i$表示 i 后重量最小的 k 个，则不难发现 $pre\_i$单减，$suf\_i$单增  
    这样的话其实如果枚举中位数较小的一个，中位数较大的一个是可以二分出来的，因为中位数较大的一个越大，$suf\_i$越大，反之越小，因此能找大最大的一个。

因此就这样边枚举边更新答案即可。

参考代码如下：  

```c++
#include <bits/stdc++.h>
using namespace std;
priority_queue<int>q;
const int N=1e5+10;
long long pre[N],suf[N];
int n,m,V;
struct node{
    int a,b;
    inline bool operator<(const node&other)const{
        return a<other.a;
    }
}a[N];
int main(){
    scanf("%d%d%d",&V,&n,&m);
    for (int i = 1; i <= n; ++i) {
        scanf("%d%d",&a[i].a,&a[i].b);
    }
    sort(a+1,a+1+n);
    int x=m&1;m>>=1;
    for (int i = 1; i <= n; ++i) {
        pre[i]=pre[i-1]+a[i].b;
        q.push(a[i].b);
        if (q.size() > m-1+x) {
            pre[i]-=q.top();
            q.pop();
        }
    }
    while(!q.empty())q.pop();
    for (int i = n; i >= 1; --i) {
        suf[i]=suf[i+1]+a[i].b;
        q.push(a[i].b);
        if (q.size() > m) {
            suf[i]-=q.top();
            q.pop();
        }
    }
    long long ans=0;
    if (x) {
        for (int i = m+1; i <= n-m; ++i) {
            if(pre[i-1]+suf[i+1]+a[i].b<=V)ans=a[i].a;
        }
        printf("%lld\n",ans);
    }
    else {
        int L,R,mid,Ans;
        for (int i = m; i <= n-m; ++i) {
            L=i+1,R=n-m+1,Ans=0;
            while (L <= R) {
                mid=L+R>>1;
                if(pre[i-1]+a[i].b+suf[mid]<=V)L=mid+1,Ans=mid;
                else R=mid-1;
            }
            if(Ans)ans=max(ans,(long long)(a[Ans].a+a[i].a));
        }
        printf("%lld\n",ans>>1);
    }
    return 0;
}
```
